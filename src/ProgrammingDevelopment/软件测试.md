# 软件测试

- **软件测试**的目的是**发现错误**，但不负责改正错误。改正错误是程序调试（Debug）的工作。
- 程序调试通常也称为 Debug
- 软件测试应严格执行测试计划，排除测试的随意性
- 对被调试的程序进行 “错误定位” 是程序调试的必要步骤

- **软件调试（Debugging）**：是在发现软件存在错误后，通过分析、定位错误的原因，进而修改代码来**改正错误**的过程。
- **软件测试（Testing）**：目的是**发现错误**，而验证软件的正确性是测试的目标之一，改善软件性能属于优化的范畴。
