# 计算机网络
## 开头
计算机网络让独立的计算机设备互联，便利人们的生活



## NAT
将网络划分为局域网和公网，解决IPv4地址耗尽问题

## DNS
DNS（Domain Name System，域名系统）用来将人类易读的域名转换为计算机使用的IP地址，让人们在浏览器中输入网址就可以连接到目标服务器，而不用记服务器复杂的IP地址。如`www.example.com`→`192.0.2.1`）。

**DNS解析过程**：
- 用户在浏览器输入URL地址
- 浏览器先查询浏览器缓存中是否有该域名对应IP地址的缓存。
- 如果没有，然后查计算机本地的Host文件中是否有该域名对应IP地址的缓存。
- 如果没有，然后向由ISP提供的本地DNS解析器发送DNS查询请求
- 如果没有，然后向根DNS服务器发出查询请求。根DNS服务器并不负责解析域名，但它能告诉本地DNS解析器应该向哪个顶级DNS服务器发送查询请求
- 本地DNS解析器然后向指定的顶级域DNS服务器发出查询请求。顶级域DNS服务器也不负责具体的域名解析，但它能告诉本地DNS解析器应该前往哪个权威DNS服务器查询该域名对应的IP地址。
- 本地DNS解析器最后向权威DNS服务器发送查询请求。
  - 权威DNS服务器是负责存储特定域名和IP地址映射的服务器。
  - 当权威DNS服务器收到查询请求时，它会查找"example.com"域名对应的IP地址，并将结果返回给本地DNS解析器
- 本地DNS解析器将收到的IP地址返回给浏览器，并且还会将域名解析结果缓存在本地，以便下次访问时更快地响应。

## CDN
CDN（Content Delivery Network，内容分发网络），通过将内容缓存到多个地理位置的节点上，让用户可以从离自己最近的节点获取资源，提高加载速度，从而减少延迟，减少源服务器的负载。

**CDN是如何加速的**：
- 用户访问网站时，CDN根据用户的地理位置将请求自动引导到最近的缓存节点。
- 如果该节点有缓存的内容（如网页、图像、视频等），它会直接将内容返回给用户，无需从源服务器获取，从而加速访问。
- 如果没有缓存内容，CDN节点会向源服务器请求并缓存数据，供后续用户访问。
